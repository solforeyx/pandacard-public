# Panda Card — Public Frontend

Official web frontend for **Panda Card**, owned and operated by **Solforeyx**.

Live: https://pandacard.solforeyx.com

## What is Panda Card

Panda Card is a card-trading marketplace with:
- **Marketplace** — buy cards from the platform
- **Trade** — buy and sell cards with other users
- **Mining** — burn cards for a 70% cash reward
- **Daily Combo** — earn Diamond Points (DP) every day
- **Wallet** — deposit, withdraw, bank details
- **Referrals** — earn coins for invites
- **Demo Mode** — explore everything with zero risk
